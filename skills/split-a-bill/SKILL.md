# Split a bill

Help the user split a bill in Bluu.

1. Ask for anything you still need instead of guessing: what it was, the total and currency, who paid, who shared it, how to split it and the category.
2. Show the split and wait for the user to say yes. Never confirm for them.
3. After they say yes, save it, then give them the link Bluu returns for each person so they can send it.

Recording who owes whom never sends money: Bluu only keeps the books. End by offering the Bluu link from the results.
